# 拓竹打印进度组件配置

此组件通过局域网 MQTT TLS 连接拓竹打印机，显示打印状态、任务名称、完成进度、剩余时间和打印层数。无需开启 LAN Only 模式。

## 获取打印机信息

在打印机屏幕中进入 **设置 → 网络**，记录以下信息：

- 打印机 IP 地址
- 打印机序列号
- Access Code（访问码）

建议在路由器中为打印机设置固定 IP。Moulin-EPDServer 与打印机必须能够通过局域网互相访问。

## 保存访问码

1. 打开 Moulin-EPDServer 的 **密钥管理** 页面。
2. 名称可填写 `bambu-access-code`。
3. Purpose 使用默认的 `General Key`。
4. 在 Secret value 中填写打印机 Access Code 并保存。
5. 记下密钥的名称或 ID。

Access Code 等同于打印机登录凭据，请勿直接填写到组件配置、提交到版本库或分享给他人。

## 组件配置

- **打印机私网 IP**：打印机的局域网 IPv4 地址，仅支持 `10.x.x.x`、`172.16.x.x` 至 `172.31.x.x`、`192.168.x.x`。
- **序列号**：打印机完整序列号。
- **访问码密钥 ID 或名称**：填写密钥管理中保存的密钥名称或 ID，不要填写 Access Code 明文。
- **卡片标题**：组件顶部显示的名称。
- **显示任务名称**：控制是否显示当前打印任务名称。
- **更新间隔**：读取打印机状态的缓存时间，默认 1 分钟。

打印机使用自签名 TLS 证书，EPDServer 会跳过证书链校验，但连接目标被限制为私网 IPv4，并且只订阅状态主题、发送状态查询命令，不提供打印控制能力。
