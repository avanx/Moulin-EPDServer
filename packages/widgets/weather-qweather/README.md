# 天气-和风天气组件配置

此组件通过 [和风天气](https://dev.qweather.com/) Web API（JWT / Ed25519）获取实时天气、小时预报与空气质量，样式与内置 `weather` 组件一致。私钥仅保存在密钥管理中，组件配置只引用密钥 ID 或名称。

官方认证说明见：[身份认证](https://dev.qweather.com/docs/configuration/authentication/)。

## 准备工作

1. 注册并登录 [和风天气控制台](https://console.qweather.com/)。
2. 创建项目，在控制台 **设置** 中查看你的 **API Host**（形如 `xxxx.qweatherapi.com`，不要带 `https://`）。
3. 记下 **项目 ID**（JWT 的 `sub`）。

## 生成并保存 Ed25519 密钥

推荐在 Moulin 管理端一键生成（私钥加密入库，公钥可随时查看）：

1. 打开 **密钥管理**。
2. 用途选择 **和风天气**。
3. 名称可填写 `qweather-ed25519`。
4. 点击 **生成密钥对**：私钥会填入「密钥内容」，公钥显示在下方。
5. **复制公钥**，稍后上传到和风控制台。
6. 点击 **保存**（私钥经 `EPD_MASTER_KEY` 加密存储）。
7. 记下该密钥的名称或 ID，填入组件的「私钥密钥 ID 或名称」。

已保存的密钥可在列表中点击 **查看公钥**，再次复制上传。

也可自行用 OpenSSL 生成 PEM，将私钥粘贴到「密钥内容」后保存；公钥仍需上传到和风控制台。

## 在和风控制台添加 JWT 凭据

1. 控制台 → **项目管理** → 打开对应项目。
2. 凭据区域点击 **添加凭据**，身份认证方式选择 **JSON Web Token**。
3. 粘贴上一步的 **完整公钥 PEM**（含 `BEGIN/END PUBLIC KEY`）并保存。
4. 创建成功后记下凭据的 **ID**，即组件里的 `kid`。

## 组件配置

| 配置项 | 说明 |
| --- | --- |
| API Host | 控制台设置中的 Host，如 `xxxx.qweatherapi.com` |
| 项目 ID (sub) | 控制台项目 ID |
| 凭据 ID (kid) | JWT 凭据创建后显示的 ID |
| 私钥密钥 ID 或名称 | 密钥管理中用途为「和风天气」的条目，不要粘贴私钥明文 |
| 地点名称 | 卡片标题显示用（如 `贵阳`），不会自动根据经纬度改写 |
| 纬度 / 经度 | 查询坐标；和风要求最多两位小数 |
| 温度单位 | 摄氏 / 华氏 |
| 显示外框 | 是否绘制外边框 |
| 更新间隔 | 服务端缓存分钟数，默认 15 |

样式：`default`（仪表盘）或 `minimal`（极简温度）。

## 使用注意

- 请求使用 `Authorization: Bearer <JWT>`，JWT 由服务端用私钥现场签名，有效期约 15 分钟。
- 空气质量或紫外线接口失败时，仍会尽量显示实况与小时预报。
- 修改地点名称或经纬度后，请先 **保存布局**，再 **立即渲染**；地点名称与经纬度需分别填写。
- 私钥等同于 API 身份，勿提交到版本库或分享给他人。
