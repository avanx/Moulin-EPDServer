# Claude Code 用量组件配置

此组件通过一次独立的 Claude OAuth 授权读取 5 小时和 7 天用量。凭据只保存在密钥管理中，请勿把本机 Claude Code 的 refresh token 贴进来：刷新时 token 会轮换，复用同一枚会把 Claude Code 登出。

## 授权并保存凭据

1. 打开 Moulin-EPDServer 的 **密钥管理** 页面，Purpose 选择 `Claude Code`。
2. 点击 **开始授权**，打开给出的链接并登录 Claude。
3. 登录后浏览器会停在 `http://localhost:18924/callback?...`。页面无法打开是正常的。
4. 复制地址栏中的完整 URL，粘贴到「回调 URL」，点击 **换取凭据**。
5. 凭据会填入密钥内容。保存密钥，并记下密钥的名称或 ID。
6. 在 Claude Code 用量组件设置中，将该名称或 ID 填入「密钥 ID 或名称」。

授权会话大约保留 10 分钟。超时、换取失败或服务重启后，请重新点击开始授权。访问令牌过期前会自动刷新，并写回同一条密钥。若授权失效，密钥会标记为已过期并停止请求，需要按以上步骤重新授权。
